# Standard: Turret Models (процедурные башни)

**Статус:** engineering standard  
**Код:** `src/game/tank/turret.ts`, `src/game/tank/turretKit.ts`  
**Инструмент:** `scripts/hull-preview.ts` (`npm run preview:models`, headless CPU-рендер)  
**Связано:** [Standard Hull Models](Standard_Hull_Models.md) · [Standard Tank](Standard_Tank.md) · [Standard Resources](Standard_Resources.md) · [Graphics Presets Matrix](Graphics_Presets_Matrix.md)

## 1. Задача, которую решает kit

Та же, что и у корпусов: башня должна быть детальной (плиты брони, мантет,
люки с перископами, оптика, ствольные коробки, болты, швы), но в сцену
обязан попадать **один меш на слот материала на часть**. Деталей в башне ещё
больше, чем в корпусе, и плюс отдельный ствол — его геометрия живёт в своей
группе (`barrelGroup`) и анимируется отдачей и зарядом, поэтому мерджится
отдельно.

| Слой | Что делает |
| ---- | ---------- |
| `TurretBuilder` × 2 | копит примитивы shell и barrel в бакеты по слоту |
| `build()` (× 2) | сливает каждый бакет в одну `BufferGeometry` |
| `turretGeometry(id)` | мемоизирует `{ shell, barrel, layout }` на процесс + `markShared` |
| `buildTurret(ctx, id)` | навешивает на слоты материалы экземпляра, ставит barrelGroup и muzzle |

`turretKit.ts` — зеркало `hullKit.ts`: объявляет `TURRET_SLOTS` и
`TurretBuilder extends PartBuilder<TurretSlot>` с типизированным API
`b.box(..., 'metal', ...)`.

## 2. Слоты материалов

| Слот | Материал | Что попадает |
| ---- | -------- | ------------ |
| `body` | `turretMat` (camo-текстура стиля) | несущие плиты башни, клин, кормовой блок, боковые апплике |
| `metal` | `metalMat` (`style.accent`) | мантет, люки, стволы, боковые ящики, ступицы, крепёж |
| `dark` | `darkMat` (`0x161a20`, фикс.) | жалюзи, перископы, эжектор, резина, сварные швы, тень под кожухом |
| `lamp` | `lampMat` (`style.glow`, `MeshBasicMaterial`) | линзы оптики, запальники огнемёта, маяки |
| `rail` | `railGlowMat` (per-tank, см. §3) | энергорельсы ствола рельсотрона, шины конденсаторов, финальный эмиттер |

`railGlowMat` создаётся **только если слот `rail` реально заполнен** —
то есть только для `railgun`. У пушки и огнемёта этого слота нет, и
`ctx.railGlowMat` остаётся `undefined` (контракт `WeaponOwner` и теста).

## 3. Per-tank материал `railGlowMat`

Энергорельсы — единственная деталь, чей материал обязан быть **per-tank**:
`railgunChargeFx` и `RailgunWeapon` в реальном времени дёргают
`emissiveIntensity` (idle → charged → overdrive при заряде). Геометрия всё
равно общая (`markShared`), а материал клонируется на каждый танк
в `buildTurret`:

```ts
if (shell.rail || barrel.rail) {
  ctx.railGlowMat = new THREE.MeshStandardMaterial({
    color: 0x111111,
    emissive: new THREE.Color(ctx.style.glow),
    emissiveIntensity: 0.15,
    roughness: 0.2,
    metalness: 0.8,
  });
}
```

Добавление новой детали в слот `rail` автоматически оживит её у всех
рельсотронов — никаких правок в `Weapon` не нужно.

## 4. Контракты анимации

`barrelGroup` анимируется тремя системами, и геометрия ствола должна им
не мешать:

| Что | Кто | Ограничение |
| --- | --- | ----------- |
| `position.z = BARREL_REST_Z - kick*0.4` | `TankAnimationSystem` (каждый кадр) | ствол садится на Z = 0.55 в покое; у всех башен одинаково |
| `position.y` (damp к `BARREL_REST_Y` = 0.5) | `railgunChargeFx` (только рельсотрон) | для рельсотрона `barrelY` обязан быть 0.5 |
| `position.x` jitter | `railgunChargeFx` (только рельсотрон) | x = 0 в покое |
| `rotation.x = 0.3` | `TankAnimationSystem.animateDeath` | ствол «роняется» вниз при гибели — мантет и ствол как единое целое |

Поэтому:
- `barrelGroup.position.set(0, layout.barrelY, BARREL_REST_Z)` — `Z` всегда
  фиксирован и равен `BARREL_REST_Z`, иначе `TankAnimationSystem` будет
  каждый кадр прыгать на `0.55`.
- `muzzle.position.z = layout.muzzleZ` — расстояние от trunnion до дула,
  разное у каждой башни (длина ствола разная).
- Мантет — часть `shell` (не анимируется), ствол проходит сквозь него.

## 5. Владение ресурсами

| Ресурс | Владелец | Кто освобождает |
| ------ | -------- | --------------- |
| merged geometry shell + barrel | `geometryCache` в `turret.ts` (`markShared`) | никто до конца процесса |
| `railGlowMat` | танк | `Tank.dispose` → `disposeObject3D` |
| прочие материалы (`bodyMat` и т.д.) | общие с корпусом, в `bodyMats` | `Tank.dispose` |

## 6. Бюджет детализации (railgun, mammoth, player)

| Башня | body verts | metal verts | dark verts | lamp verts | rail verts | Σ shell | barrel verts | мешей (hull + turret) |
| ----- | ---------- | ----------- | ---------- | ---------- | ---------- | ------- | ------------ | --------------------- |
| railgun     | 12 | 3220 | 1952 |  12 | 240 | 5436 |  720 | 5 + 8 = **13** |
| flamethrower| 12 | 2640 | 1620 |  24 |   0 | 4296 |  596 | 5 + 6 = **11** |
| cannon      | 12 | 2880 | 1820 |  12 |   0 | 4724 |  640 | 5 + 6 = **11** |

Габариты башен (локальные, земля башни = Y=0 на кольце корпуса, нос = +Z):

| Башня | Длина (Z) | Ширина (X) | Высота (Y) | `barrelY` | `muzzleZ` |
| ----- | --------- | ---------- | ---------- | --------- | --------- |
| railgun      | 5.6 | 2.9 | 1.5 | 0.50 | 3.20 |
| flamethrower | 3.0 | 3.1 | 1.7 | 0.45 | 1.95 |
| cannon       | 3.6 | 2.9 | 1.8 | 0.55 | 2.80 |

Тест `keeps the gun inside a sane detail budget` держит вилку 600–20 000
вершин на башню (shell + barrel). Тест `produces three visibly different
silhouettes` ловит случайное схлопывание силуэтов: рельсотрон обязан быть
длиннее остальных по Z, огнемёт — короче и выше.

## 7. Дизайн башен

Соглашения: **+Z — вперёд, +X — вправо, Y — вверх, Y=0 — кольцо башни
(стык с кольцом корпуса)**. Мантет всегда спереди, ствол выходит из
trunnion на `barrelY` и идёт в +Z. Люки, перископы и оптика — на крыше;
баки и катушки заряда — на корме.

| Башня | Силуэт | Ключевые детали |
| ----- | ------ | --------------- |
| `railgun` | низкий клин, длинный ствол | наклонный носовой клин, кольцо башни с болтами, кормовой блок конденсаторов (3 цилиндра + шина `rail`), оптический прицел с линзой, сенсорная мачта, дымовые гранатомёты на щеках, запасные траки, корзина ЗИП, манлет с тёмным окном; ствол — открытая рама с двумя glowing-рельсами сверху, 4 кольца ускорителя, фокусирующий узел из 3 цилиндров и финального эмиттера `rail` |
| `flamethrower` | литой купол, близкий бой | усечённый купол (squashed sphere) + пояс с болтами, 2 топливных бака на корме с вентилями и хомутами, манифольд, шланги по поверхности купола к манлету (`shellHose`), 2 смотровые щели, козырёк прицела, бортовые ящики ЗИП, манлет; ствол — блок с двумя соплами, кольца поджига, **пилотное пламя** (`lamp`) на кончиках, теплозащитный кожух |
| `cannon` | бокси, скорострельная | бокси-корпус со скошенным носом, кормовой автозагрузчик с 2 аммо-барабанами и лотком подачи, стеллаж ЗИП, пулемёт на крыше, оптический прицел, дымовые гранатомёты, корзина, манлет; ствол — массивная труба с эжектором, кольца термокожуха, 2 цилиндра противоотката, **щелевой дульный тормоз** (`muzzleBrake`: 2 манжета + тёмная средняя часть + 6 рёбер) |

## 8. Хелперы авторинга

В `turret.ts` есть локальные помощники, чтобы детали не плодили
дублирующий код:

| Хелпер | Что строит |
| ------ | ---------- |
| `turretRing(t, rTop, rBot)` | кольцо башни + обод + кольцо болтов |
| `cupola(t, x, y, z, r)` | командирская башенка: корпус, люк, ручка, 5 перископов |
| `smokeLaunchers(t, side, x, y, z)` | блок 3 дымовых гранат на щеке |
| `basket(t, w, h, d, x, y, z)` | сварная клетка-корзина (рамка + прутья) |
| `optic(t, x, y, z, len, r)` | бронированный прицел с линзой `lamp` |
| `spareLinks(t, side, x, y, z, n, step)` | ряд запасных траков на борту |
| `shellHose(t, R, cy, sy, side, x, zFrom, zTo, steps)` | шланг, повторяющий сферическую поверхность (для огнемёта) |
| `muzzleBrake(b, z, len, r, ribs)` | щелевой тормоз: 2 манжета + тёмный средний + `ribs` рёбер |

## 9. Чеклист при правке башни

- [ ] Новая деталь добавляется через `TurretBuilder` (shell или barrel), а не отдельным `Mesh`
- [ ] Деталь отнесена к правильному слоту (`dark` — углубления, `metal` — железо, `body` — броня, `rail` — только если хотим оживить через `railGlowMat`)
- [ ] `barrelGroup.position.set(0, layout.barrelY, BARREL_REST_Z)` — Z всегда `BARREL_REST_Z`
- [ ] `muzzle.position.z` отстоит от trunnion на длину ствола (а не от мантета)
- [ ] Если деталь «светится» — она в `lamp` (статично) или `rail` (анимируется)
- [ ] Прогнаны `npm run typecheck`, `npm test` (в т.ч. `turretGeometry.test.ts`)
- [ ] Просмотрен `npm run preview:models` — силуэт и пропорции не сломаны
