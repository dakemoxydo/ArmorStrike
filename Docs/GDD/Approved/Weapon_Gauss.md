# Weapon: Gauss — Пушка «Гаусс»

**Статус:** Approved  
**Тип:** Lock-on Hitscan + Auto-fire  
**Связано:** [[Damage_System]], [[Tank_Aim]], [[Target_Highlight_Aim]], [[Match_Framework]]

## Фэнтези

Высокоточное снайперское электромагнитное орудие с захватом цели: игрок удерживает прицел в сторону видимого врага при зажатой ЛКМ, на враге появляется прицельная рамка и заполняющийся круг захвата; по достижении 100% орудие производит автоматический разрушительный гиперзвуковой залп.

## Тюнинг (`WEAPON_TUNING.gauss`)

| Параметр | Значение | Описание |
|----------|----------|----------|
| `damage` | 65 | сокрушительный снайперский урон при 100% захвате |
| `arcadeDamage` | 30 | быстрый аркадный урон навскидку (без автозахвата) |
| `lockTime` | 1.3 с | время непрерывного удержания для 100% захвата цели |
| `reloadTime` | 2.2 с | cooldown после снайперского выстрела |
| `arcadeReloadTime` | 1.05 с | быстрый cooldown после аркадного выстрела навскидку |

| `arcadeRange` | 85.0 м | предельная дальность аркадного выстрела |
| `lockConeAngle` | 0.075 рад (~4.3°) | узкий снайперский сектор захвата (требует точного наведения) |
| `knockback` | 16.0 | отдача и импульс отталкивания снайперского выстрела |
| `arcadeKnockback` | 6.0 | отдача аркадного выстрела навскидку |

`turretSpeed`: 6.5 рад/с.

## Режимы огня и FSM

Оружие поддерживает два взаимодополняющих режима:
1. **Беглый аркадный огонь (навскидку):** клик ЛКМ без захваченной цели либо отпускание ЛКМ до завершения захвата производит мгновенный выстрел лучом по направлению ствола (`arcadeDamage: 30`, КД `1.05 с`).
2. **Снайперский автозахват:** удержание ЛКМ при наведении на врага в конусе ~4.3° запускает накопление заряда (1.3 с). По достижении 100% производится автоматический снайперский залп (`damage: 65`, КД `2.2 с`).

```
                 isTriggerActive (ЛКМ) + enemy in lock cone + LOS
    IDLE ────────────────────────────────────────────────────────► LOCKING
      ▲   ▲                                                          │
      │   │          lost LOS / dead / cone exit / switch target     │
      │   ├──────────────────────────────────────────────────────────┤
      │   │                                                          │
      │   │   release ЛКМ (тап / до 100%)                            │
      │   │   └──► executeArcadeFiring() (30 dmg)                    │
      │   │        │                                                 │
      │   │        ▼                                                 │
      │   │      COOLDOWN (1.05 c)                                   │
      │   │        │                                                 │
      │   └────────┴─────────────────────────────────┐               │
      │                                              │               │
      │                                              │      lockTimer ≥ lockTime
      │                                              │               ▼
      │                                              │      executeSniperFiring() (65 dmg)
      │                                              │               │
      └──────────────────────────────────────────────┴────── COOLDOWN (2.2 c)
                                                              reloadTimer → 0
```

1. **IDLE:** орудие готово к стрельбе (`ammo = 1`, `isCharging = false`). При клике без цели в конусе сразу производится аркадный выстрел.
2. **LOCKING:** игрок удерживает ЛКМ, орудие наведено в узкий сектор (~4.3°) на врага. В HUD на экране появляется прицельная метка с кругом захвата (0..100%). Соленоидные катушки башни усиливают свечение (`railGlowMat.emissiveIntensity: 0.2 → 4.4`), звучит нарастающий гул разгона конденсаторов.
3. **Отпускание ЛКМ:** если игрок отпускает спуск до 100%, орудие производит быстрый аркадный выстрел навскидку в текущем направлении ствола (`arcadeDamage: 30`, КД 1.05 с).
4. **Срыв захвата укрытием:** если цель зашла за стену (`!losClear`) или погибла — накопленный заряд сбрасывается в 0, а флаг `needsTriggerRelease` блокирует паразитные случайные выстрелы в стену до нового нажатия.
5. **Снайперский выстрел (100% готовность):** при полном заполнении круга происходит автоматический залп на 65 ед. урона с тяжелой отдачей (16.0) и переходом в `COOLDOWN` на 2.2 с.
5. **COOLDOWN:** орудие охлаждается (`ammo = 0`, `reloading = true`).

## Предупреждение о захвате (Lock-On Warning)

Когда бот или вражеский игрок захватывает танк игрока пушкой «Гаусс», у жертвы активируется система раннего предупреждения:
- **Аудио:** ритмичный двухтональный тревожный зуммер WebAudio (`AudioPort.lockWarning()`).
- **HUD:** пульсирующий красный баннер `.incoming-lock-banner` («ТРЕВОГА: ЗАХВАТ ЦЕЛИ») в верхней части экрана, оповещающий игрока о необходимости сорвать захват укрытием за 1.3 секунды.

## Визуальные и звуковые эффекты

- **3D-модель башни (`turret.ts`):** футуристическая широкая стелс-рубка с боковыми радиаторными решётками охлаждения, кормовой энергомодуль с 4 вертикальными накопительными банками суперконденсаторов и высоковольтными шинами (`rail`), двухканальный оптико-локационный комплекс автозахвата на крыше и сдвоенный электромагнитный ускоритель (два параллельных ствола с четырьмя синхронизированными ступенями соленоидных катушек `rail`, продольными волноводами и центральным дульным коллиматором сведения полей).
- **HUD (`HUD.tsx`, `useGameHud.ts`, `hud.css`):** независимый элемент `.gauss-target-reticle`, проецируемый из мировых координат захваченного врага в экранные проценты (`lockTargetX`, `lockTargetY`), с динамическим размером под перспективную дистанцию (`clamp((30 / dist) * 72, 24, 140)` px), кольцевым SVG-индикатором `--charge-prog` и угловыми рамками `[ ⬡ ]` неонового фиолетового цвета (`#c084fc`), вспыхивающими белым при 100% готовности к выстрелу.
- **Аудио (`audio.ts`):** нарастающий тон зарядки (`chargeRailgun`) + сокрушительный хлопок сверхзвукового удара и разряда конденсаторов при выстреле (`shoot('gauss')`).
