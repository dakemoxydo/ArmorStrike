# Weapon: Gauss — Пушка «Гаусс»

**Статус:** Approved  
**Тип:** Lock-on Hitscan + Auto-fire  
**Связано:** [[Damage_System]], [[Tank_Aim]], [[Target_Highlight_Aim]], [[Match_Framework]]

## Фэнтези

Высокоточное снайперское электромагнитное орудие с захватом цели: игрок удерживает прицел в сторону видимого врага при зажатой ЛКМ, на враге появляется прицельная рамка и заполняющийся круг захвата; по достижении 100% орудие производит автоматический разрушительный гиперзвуковой залп.

## Тюнинг (`WEAPON_TUNING.gauss`)

| Параметр | Значение | Описание |
|----------|----------|----------|
| `lockTime` | 1.15 с | время непрерывного удержания для 100% захвата цели |
| `reloadTime` | 2.8 с | cooldown после выстрела до готовности к следующему захвату |
| `damage` | 115 | колоссальный снайперский урон (ваншот Speedy [70 HP], критический Viking [80 HP] и Hunter [100 HP]) |
| `range` | 110.0 м | предельная дальность захвата цели |
| `lockConeAngle` | 0.075 рад (~4.3°) | узкий снайперский сектор захвата (требует точного наведения) |
| `knockback` | 16.0 | отдача стрелка и импульс отталкивания цели |
| `magazine` | 1 | однозарядный конденсаторный цикл |
| `beamDuration` | 0.7 с | время видимости гиперзвукового трассера выстрела |
| `fireShakePlayer` | 0.52 | сотрясение камеры стрелка |
| `fireShakeBot` | 0.16 | сотрясение камеры от выстрела бота поблизости |

`turretSpeed`: 8.5 рад/с.

## FSM состояния оружия

```
                 isTriggerActive (ЛКМ) + enemy in lock cone + LOS
    IDLE ────────────────────────────────────────────────────────► LOCKING
      ▲                                                              │
      │   release ЛКМ / lost LOS / dead / cone exit / switch target  │
      ├──────────────────────────────────────────────────────────────┤
      │                                                              │
      │                                                     lockTimer ≥ lockTime
      │                                                              ▼
      │                                                     executeFiring() (100% auto)
      │                                                              │
      └────────────── COOLDOWN ◄─────────────────────────────────────┘
                      reloadTimer → 0
```

1. **IDLE:** орудие готово к наведению (`ammo = 1`, `isCharging = false`).
2. **LOCKING:** игрок удерживает ЛКМ, орудие наведено в узкий сектор (~4.3°) на врага. В HUD на экране появляется прицельная метка с кругом захвата, «приклеенная» к врагу и масштабирующаяся по дальности (0..100%). Соленоидные катушки башни усиливают свечение (`railGlowMat.emissiveIntensity: 0.2 → 4.2`), звучит нарастающий гул разгона конденсаторов.
3. **Срыв захвата и сброс заряда:** если игрок отпустил ЛКМ, цель зашла за стену (`!losClear`), прицел ушёл за пределы сектора удержания (строгий гистерезис ×1.08 ≈ 4.6°) либо игрок перевёл прицел на другого врага — накопленный заряд **не переносится**, таймер мгновенно сбрасывается в 0, а орудие возвращается в `IDLE`.
4. **Выстрел (100% готовность):** при полном заполнении круга происходит автоматический выстрел, наносящий 115 ед. урона, вспышка на срезе ствола, фиолетово-плазменный гиперзвуковой луч и переход в `COOLDOWN` на 2.8 с.
5. **COOLDOWN:** орудие охлаждается (`ammo = 0`, `reloading = true`).

## Визуальные и звуковые эффекты

- **3D-модель башни (`turret.ts`):** футуристическая широкая стелс-рубка с боковыми радиаторными решётками охлаждения, кормовой энергомодуль с 4 вертикальными накопительными банками суперконденсаторов и высоковольтными шинами (`rail`), двухканальный оптико-локационный комплекс автозахвата на крыше и сдвоенный электромагнитный ускоритель (два параллельных ствола с четырьмя синхронизированными ступенями соленоидных катушек `rail`, продольными волноводами и центральным дульным коллиматором сведения полей).
- **HUD (`HUD.tsx`, `useGameHud.ts`, `hud.css`):** независимый элемент `.gauss-target-reticle`, проецируемый из мировых координат захваченного врага в экранные проценты (`lockTargetX`, `lockTargetY`), с динамическим размером под перспективную дистанцию (`clamp((30 / dist) * 72, 24, 140)` px), кольцевым SVG-индикатором `--charge-prog` и угловыми рамками `[ ⬡ ]` неонового фиолетового цвета (`#c084fc`), вспыхивающими белым при 100% готовности к выстрелу.
- **Аудио (`audio.ts`):** нарастающий тон зарядки (`chargeRailgun`) + сокрушительный хлопок сверхзвукового удара и разряда конденсаторов при выстреле (`shoot('gauss')`).
