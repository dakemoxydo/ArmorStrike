## Intent

Танки и HUD уже говорят на языке **комикс / cel-shade / чернильный контур**.
Мир, свет, частицы и часть UI ещё говорят на языке **PBR-сим / кибернеон / фото-выветривание**.
Игрок видит два разных продукта в одном кадре.

Цель прохода — не «добавить графики», а **подогнать всё, что не танк, под уже принятый арт-дирекшен**,
плюс 3–4 хода, которые делают бой приятнее читать (фракция, трассеры, смерть, первый кадр меню).

Анти-цели:

- Не возвращать GLB-реализм (`MODELS_ENABLED` остаётся выкл.).
- Не вводить новый полноэкранный постпроцесс (Sobel/outline-pass, SSAO, DOF).
- Не ломать бюджет кадра: пулы частиц константны, ink-outline на всю деревню — только если DC ок.
- Не менять `Russo One` / `Exo 2` и янтарную UI-палитру `#f59e0b` (H13).

## Диагноз: два пайплайна в одном кадре

| Слой | Сейчас | Должен быть |
|---|---|---|
| Танки | 3-band cel + inverted-hull ink + графичный камуфляж | ✓ уже цель |
| HUD / меню (часть) | чернила, срез, бумага, янтарь | ✓ уже цель |
| Освещение сцены | `ACESFilmicToneMapping` + `RoomEnvironment` PMREM | плоский toon-ключ, без киношного IBL |
| Bloom | `UnrealBloomPass` только на `high` | либо selective по эмиссиям, либо выкл. (размывает контур) |
| Земля | 3072² + `noise()`, завод `#151920` (ночь) | крупные плашки, без перлина, palettes дня |
| Деревня | штукатурка с трещинами, выветривание, grain | графичные фасады, чёткие швы, без микрошума |
| Город | noon-небо + `NEON.cyan/magenta/lime` | либо дневной комикс-город, либо сумеречный неон — не оба |
| FX | мягкие радиалы дыма/пыли, puff-трасс снаряда | жирные болты, жёсткие вспышки, ink-кольца |
| Неймплейты | `roundRect` + системный sans | срез + Russo One + чернильная обводка |
| Остовы | примитивные боксы без cel/ink | силуэт корпуса + графичный пожар |
| Модалки (auth/crate/garage stats) | Tailwind `cyan-*` (H13 leftover) | янтарь `--accent` |
| Игрок | корпус `COLORS.player = 0x2ee6c0` (мята) | янтарь/белый акцент, не циановый герой |

Код-якоря: `src/game/RenderWorld.ts` (ACES + RoomEnvironment + UnrealBloom),
`src/game/textures/ground.ts` (`noise()`), `src/game/textures/village.ts` (выветривание),
`src/game/arena/cityMap.ts` (`NEON`), `src/game/nameplate.ts`,
`src/game/effects/WreckSystem.ts`, `src/game/engine/ProjectileBehavior.ts` (`trailPuff`),
`src/core/constants.ts` (`COLORS.player`), `src/components/{AuthModal,CrateOpeningModal,Garage}.tsx`.

## Что уже не трогать

- Геометрия корпусов/башен (`hull.ts` / `turret.ts`) — силуэты читаемые, превью это подтверждают.
- `applyCelShading` + `attachComicInkOutline` на танках.
- Токены UI (`variables.css`, H12/H13) — язык панелей верный.
- Комиксные бейджи CP (`CaptureMarkers.drawLetterBadge`).
- Числа урона (`.dmg-float`) — уже комикс.
- Атмосферы карт как *намерение* (полдень / закат / деревенский день) — править palettes земли, не сами пресеты.

## Предложения (ранг = красота / час)

### A. Дёшево, сразу «одна игра» (UI + идентичность) — **срез 1, shipped**

1. **Добить H13-циан.** ✓ Auth, контейнеры, UserBadge, паспорт гаража, `useGameHud` conic-gradient,
   заводские lane-glow, `COLORS.player` → `0xf59e0b`, boost-jet игрока. Рельса/Изида остаются мятными (оружие).
2. **Неймплейты в язык HUD.** ✓ Срез, `Russo One`, 8-dir ink, HP как HUD. E2 fade 48–110 м.
3. **Герой игрока не мятный.** ✓ FFA олива `#6b7a32` + золото `#d4c070`. TDM/CP корпус фракции уже был.

### B. Свет и постпроцесс — **срез 1, shipped (п.4–5); п.6 открыт**

4. **Снять киношный IBL.** ✓ `scene.environment = null`, `LinearToneMapping`.
5. **Bloom не Unreal.** ✓ выключен на всех пресетах.
6. **Небо графичными пятнами.** ✓ shipped 2026-09-23: fragment-шейдер неба в
   `RenderWorld.ts` — 3 плоские полосы (zenith/mid/horizon через `step`),
   пятна облаков через жёсткий `step(0.38, field)`, плоский диск солнца с
   кольцом; без smoothstep-градиентов и pow-свечений.

### C. Мир под стиль танков

7. **Земля без перлина.** ✓ Завод `#b89a72`, деревня поля `#5a7a38`, город `#7a8490`. `noise()` с земли снят.
8. **Деревня — иллюстрация, не фото.** Штукатурка: 2–3 тона блоков + чернильный шов.
   Убрать трещины/grain/exposed-brick specks. Крыши — крупные чешуйки, не thatch-шум.
9. **Город: выбрать одно время суток.** ✓ shipped 2026-09-23 — **дневной
   комикс-мегаполис (OQ2):**
   - ✓ Вывески = нарисованные плакаты (`posterTexture`), не emissive neon;
     окна — графичная сетка, не glow (`glass()` без emissive, skyline —
     пастельные дневные тона); NEON — плоская палитра краски, не источник
     света; столб/капитель плазы, under-strip эстакады, ramp, crate, dome —
     normal blending без emissive/addivite; dust — дневной `0xdfe8f0`.
   - Сумеречный неон — отклонён (не оба).
10. **Ink на крупных зданиях** (не на каждом заборе). ✓ shipped 2026-09-21 (OQ4 = да):
    только несущие wall-корпуса выше порога (`shouldOutlineBuilding`: h ≥ 4 м и
    max(w,d) ≥ 8 м или h ≥ 8 м), ≤2 шелла на корпус, shared-материал 0.06 м.
    Census: factory 545→601 / village 790→860 / city 484→532 (все < +15% DC).
    Мелочь и скайлайн контура не получили — fallback не понадобился.

### D. Бой приятнее читать

11. **Жирный трассер Смоки.** ✓ Аддitive болт + ribbon 8.4 м, `trailInterval = Infinity`.
12. **Комикс-импакт.** Вспышка = жёсткий диск + 6–8 ink-линий (speed lines), не мягкий radial.
    Кольцо уже есть (`RingSystem`) — сделать непрозрачным с чернильным краем, не additive-white.
13. **Остов = тот же корпус.** ✓ shipped 2026-09-23: `WreckSystem` слитый
    силуэт `hullGeometry(hullId)` + сбитая башня `turretGeometry(turretId)`
    в графитном cel-материале (`0x35353d`), 2–3 ember-плашки и столб дыма;
    процесс-кэш + markShared, слоты преаллоцированы (ноль аллокаций в бою).
    Пины — `wreckSilhouette.test.ts`.
14. **Смерть по оружию** (без новых мешей): рельса — чистый разрез + белая вспышка;
    огнемёт — догорающий корпус; гаусс — отброс остова; смоки — кольцо + обломки.
15. **Щит респавна.** Вместо молочной additive-сферы — пунктирное ink-кольцо + комиксные звёзды.

### E. Первый кадр (меню / гараж)

16. **Подиум, не пустота.** ✓ shipped 2026-09-23: `MenuStage` — бумажный пол +
    подиум с Ben-Day/янтарным кольцом на `PREVIEW_POS` + чернильный рим +
    цикл-стена r=26; в меню/гараже арена скрыта и туман выключен
    (`GameModeController.setMode` + `RenderWorld.setFogEnabled`), видимостью
    гейтит `PreviewController`. Пины — `menuStage.test.ts`,
    `gameModeLifecycle.test.ts` (stage gating), `renderWorldQuality.test.ts`
    (setFogEnabled).
17. **Рим-свет гаража сильнее.** Предпросмотр — витрина: тёплый key + холодный rim,
    без тени-кляксы на земле.

3. **Bloom:** ✓ выключен совсем на всех пресетах (срез 1).

5. **Трогать ли геометрию танков?** Рекомендация — нет в этом проходе (силуэты уже ок).
   Увеличение башен +20% — из TO-черновика п. 27, отдельный пункт.

## Acceptance

Проход считается согласованным к реализации, когда:

- Выбраны ответы на OQ 1–4.
- Есть приоритетный срез (предлагается **A + B + 11 + 13** как первый дифф).
- Каждый пункт имеет файловый якорь и не требует нового render pass.
- `npm run census` после ink-на-зданиях (если выбран OQ4=да) не хуже baseline +15% DC.

После утверждения: код → `Stylized_Art_Direction.md` дополняется секциями «мир / FX / свет»;
`Standard_Cel_Shaded_Rendering.md` — tone mapping и environment.
